# Supply Chain & Inventory Optimization Analytics

## Project Overview
An end-to-end data analytics project focused on supply chain operations, sales performance, shipping delays, and order fulfillment. The project uses Python, PostgreSQL, and Tableau Public to transform raw supply chain data into meaningful business insights.

## Business Objectives
- Analyze sales performance across product categories and regions.
- Evaluate shipping delays across different shipping modes.
- Understand order status distribution and order fulfillment patterns.
- Identify potential operational inefficiencies.
- Build a dashboard to support data-driven business decisions.

## Tools & Technologies
- **Python:** Data cleaning, preprocessing, exploratory data analysis, and data quality checks.
- **Pandas & NumPy:** Data manipulation and analysis.
- **PostgreSQL:** Data storage and SQL-based business analysis.
- **SQL:** Aggregations, grouping, filtering, and performance analysis.
- **Tableau Public:** Interactive dashboard development.
- **Excel:** Additional data review and reporting, where applicable.

## Project Workflow
1. Collected and loaded the supply chain dataset.
2. Inspected the dataset structure, missing values, and duplicate records.
3. Standardized column names and prepared the data for analysis.
4. Performed exploratory data analysis using Python.
5. Loaded the prepared data into PostgreSQL.
6. Executed SQL queries to analyze sales, regions, shipping performance, and order statuses.
7. Developed a Tableau dashboard containing KPI cards and business charts.

## Key Performance Indicators
- Total Sales
- Total Orders
- Average Delivery Delay (Days)

## Dashboard Visualizations
- Sales by Product Category
- Average Delivery Delay by Shipping Mode
- Total Sales by Region
- Order Count by Order Status

## Business Questions
- Which product categories generate the highest sales?
- Which regions contribute the most sales?
- Which shipping modes have the highest average delivery delays?
- How are orders distributed across different statuses?
- Where could supply chain operations be improved?

## Business Value
This project demonstrates practical data analytics skills, including data preparation, SQL analysis, KPI development, and dashboard reporting. The findings can help stakeholders investigate regional performance, shipping efficiency, and order fulfillment.
